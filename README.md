# CodeLab  

**CodeLab** es un laboratorio de código donde desarrollo y experimento con soluciones **Fullstack**, aplicando buenas prácticas y explorando diferentes tecnologías.  

## 🎯 Objetivos  
- Probar ideas y conceptos de **arquitectura limpia**.  
- Integrar servicios y **APIs** en entornos reales.  
- Practicar patrones de diseño y principios **SOLID**.  
- Documentar aprendizajes y compartir ejemplos prácticos.  

## 🛠️ Tecnologías principales  
- **Backend**: .NET Core  
- **Frontend**: Angular  
- **Base de datos**: SQL Server  
- **Infraestructura**: Docker  
- **Mensajería y caché**: RabbitMQ, Redis  
- **Otros**: integración de APIs, optimización de procesos y pruebas.  

## 📂 Contenido  
Este repositorio incluye:  
- Ejemplos de proyectos y prototipos.  
- Pruebas de integración con diferentes stacks.  
- Notas y guías rápidas sobre herramientas y librerías.  

---

> 💡 Este espacio está en constante evolución, pensado como un **sandbox de aprendizaje y práctica**.
